## 项目简介

基于 GitHub Pages 的单页静态作品展示站，以「六幕」结构呈现个人履历、体育赛事作品与获奖经历，风格取材自电影分镜与 Moonrise Kingdom 配色。

## 内容板块

- **人物表** —— 个人基本信息（滇池学院 · 数字媒体技术）
- **取景地** —— 教育经历
- **三场戏** —— 活动 / 赛事组织经历（3v3 篮球赛统筹、运动会志愿者、篮球社财务）
- **道具清单** —— 技能栈（摄影 / 剪辑 / Office / 1+X 认证）
- **记分牌** —— 获奖经历（CUBA 云南赛区、开大杯、新生杯等）
- **三帧剧照** —— 作品展示（交易 / 善意 / 守护者）

## 技术栈

- 纯静态单页 HTML，图片全部 base64 内嵌，无外部文件依赖
- GSAP 动画 / 自定义字体（Playfair Display · Special Elite · Caveat）
- 托管于 GitHub Pages
